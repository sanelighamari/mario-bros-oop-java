# 🍄 Super Mario Bros Clone - Base Project (Java)

![Java Version](https://img.shields.io/badge/Java-21-orange.svg)
![Paradigm](https://img.shields.io/badge/Paradigm-OOP-blue.svg)

A playable core engine of Super Mario Bros developed for the command-line terminal. This project was built as a coursework assignment for the Programming Technology I class (Universidad Complutense de Madrid - UCM).

## 🧠 Technical Focus: OOP
The main goal of this base version is to establish the pillars of **Object-Oriented Programming (OOP)** in Java:
- **Inheritance & Polymorphism:** Created a class hierarchy using the abstract `GameObject` class and the `GameItem` interface.
- **Encapsulation:** Managed game state and positions using strict access modifiers.
- **Exception Handling:** Used `try-catch` blocks and custom exceptions to handle invalid inputs safely.
